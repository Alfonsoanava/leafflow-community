# LeafFlow Community Initiative

Official website for the LeafFlow Community Initiative.

LeafFlow supports libraries through education, technology, and responsible digital tools—helping people grow, learn, and create new opportunities.

LeafFlow is part of the wider A-Team ecosystem alongside Chain Cats, Discord, Telegram, and the community's connected projects and apps.

## Website files

- `index.html` — website content and structure
- `styles.css` — responsive LeafFlow design
- `script.js` — mobile menu and contract-address copy button

## Publishing

This is a static website ready for GitHub and Cloudflare Pages. No build command is required. Use the repository root as the output directory.
